# Melike Arslan — Portfolio

Kişisel portfolyo ve blog sitesi. Next.js (App Router), TypeScript ve Tailwind CSS ile geliştirildi.

## Özellikler

- Türkçe / İngilizce dil desteği (next-intl)
- MDX tabanlı blog
- Deneyim, eğitim, projeler ve gönüllülük geçmişi

## Geliştirme

npm install
npm run dev

http://localhost:3000 adresini aç.
